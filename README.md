## 🚀 What It Does

FarmSense AI is a Gemma 4-powered farm assistant that gives Nigerian farmers instant, practical agricultural advice — by text or by photo — in the language they actually speak.

A farmer can:
- **Chat with the AI** in English, Hausa, Yoruba, Igbo, or Nigerian Pidgin about crop diseases, fertilizer choices, pest control, planting timing, or storage
- **Upload a photo of a sick crop** and get a real diagnosis and treatment advice powered by Gemma 4's multimodal vision — no agronomist required
- **Check farm credit eligibility** using their own farm data (state, crop, farm size, loan amount) for an AI-generated credit assessment
- **Run a satellite farm health scan** (simulated NDVI/soil/coverage readings) and get an AI-generated, data-grounded recommendation
- **Try a USSD simulator** (`*347*55#`) demonstrating how the same assistant could work on a basic feature phone with no internet or smartphone required

## 🧠 Gemma 4 Integration

Every AI response in this app is generated by **Gemma 4**, called directly via the **Gemini API on Google AI Studio** — no other model or provider is used.

| Component | Detail |
|---|---|
| Model | `gemma-4-31b-it` — instruction-tuned, 140+ languages, strong reasoning |
| API | Google AI Studio / Gemini API `generateContent` endpoint |
| Architecture | Browser → `/api/chat` (Vercel serverless function) → Gemma 4. The API key is read from a server-side environment variable and is never sent to or visible from the browser. |
| Text chat | Multilingual farming Q&A (English, Hausa, Yoruba, Igbo, Pidgin) |
| Vision | Native multimodal image understanding for crop/pest photo diagnosis — Gemma actually analyzes the photo pixels (discoloration, spots, holes, insects), it does not just caption it |
| Grounded generation | Farm credit and satellite scan prompts are built from the farmer's **real, structured input data** (form fields / scan readings), not generic placeholder text — Gemma reasons over that specific data each time |
| Thinking mode | Configured with `thinkingLevel: minimal` and a response filter (applied server-side and client-side) that strips any internal reasoning/thought tokens, so farmers only ever see the final, direct answer |

This is intentionally **not** a basic chatbot wrapper — Gemma drives four distinct, functionally different features (conversational advice, image diagnosis, structured credit assessment, and data-grounded satellite recommendations), each with its own tailored system prompt.

## 🌍 The Problem

- **70%+ of Nigerians** depend on agriculture for income, yet most farmers have no access to an agronomist when a crop starts failing
- **No smartphone, no help** — most existing agri-tech tools assume a smartphone and stable internet, excluding a large share of rural farmers
- **Language is a barrier** — almost no agricultural AI tools support Hausa, Yoruba, Igbo, or Pidgin, the languages farmers actually speak
- **No access to financing** — even when a farmer knows what's wrong, they often can't access credit to fix it
- **No early warning** — crop stress is often invisible to the naked eye until it's too late to save the harvest

## 💡 Features

### 🌱 AI Chat Assistant
A multilingual farming advisor. A farmer types a question and gets a direct, practical answer in their language of choice.

### 📷 Photo-Based Crop Diagnosis
A farmer uploads (or takes) a photo of a sick plant, and Gemma 4's vision capability analyzes it and returns a diagnosis plus treatment advice.

### 💰 Farm Credit Eligibility Check
A farmer fills in their name, state, crop, farm size, and requested loan amount. Gemma assesses eligibility using that exact data and returns a score, status, recommended loan amount, interest rate, and advice.

### 🛰️ Satellite Farm Health Scan
Simulates satellite readings (NDVI vegetation index, soil moisture, crop coverage, disease risk) and asks Gemma to turn those specific numbers into a concrete, actionable recommendation.

### 📶 USSD Simulator
Demonstrates how the same assistant could be reached via `*347*55#` on any basic phone — a design proof for reaching farmers without smartphones or data.

## 🛠️ Tech Stack

```
Frontend      → HTML5 / CSS3 / Vanilla JS (mobile-first, single-file, no framework)
Backend       → One Vercel serverless function (api/chat.js) that proxies to Gemma 4
AI Inference  → Gemma 4 (gemma-4-31b-it) via Google AI Studio's Gemini API
```

The frontend never talks to Google directly — it calls `/api/chat`, and the serverless function (running server-side on Vercel) forwards that to Gemma 4 using a key stored in an environment variable. This keeps the real API key out of the browser and out of the public repo entirely.

## 🚀 Getting Started (Deploy on Vercel)

### Prerequisites
- A free [Vercel](https://vercel.com) account (sign in with GitHub)
- A free Google AI Studio API key → [aistudio.google.com/apikey](https://aistudio.google.com/apikey)

### Deploy it

1. On [vercel.com](https://vercel.com), click **Add New → Project → Import** this GitHub repo.
2. Leave the build settings as default (no build command needed — it's a static file plus one serverless function).
3. Before deploying, add an **Environment Variable**:
   - Key: `GEMINI_API_KEY`
   - Value: your Google AI Studio key
4. Click **Deploy**. Vercel will host `index.html` and automatically turn `api/chat.js` into a live serverless endpoint at `/api/chat`.
5. Visit your Vercel URL — the app calls `/api/chat`, which calls Gemma 4 using the key from your environment variable. No key ever appears in the browser or in this repo.

### Run it locally (optional, for development)

```bash
npm install -g vercel
vercel dev
```
This runs both the static frontend and the `/api/chat` function locally, using a `.env` file (see `.gitignore` — `.env` is never committed) with `GEMINI_API_KEY=your_key_here`.

## 🔐 Security Note on the API Key

Earlier versions of this project called Gemma 4 directly from the browser, which meant the API key had to live in client-side code — visible to anyone who viewed the page source. **This version fixes that**: the key now lives only in a server-side environment variable (`GEMINI_API_KEY`), read by the `api/chat.js` serverless function. The browser only ever talks to `/api/chat` on this app's own domain, never to Google directly.
